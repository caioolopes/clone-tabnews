# clone-tabnews

## Desenvolvimento

Inicie o banco e o servidor de desenvolvimento com:

```bash
npm run dev
```

## Testes

Execute a suíte com:

```bash
npm test
```

Os testes usam uma porta, um banco de dados e um serviço de e-mail isolados do
ambiente de desenvolvimento, então podem ser executados mesmo com o servidor
local em funcionamento.
